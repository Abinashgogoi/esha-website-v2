ESHA Hub Members Module

Files:
- executive-members.html
- member-profile.html
- members.css
- members-data.js
- members.js
- assets/members/

Setup:
1. Place verified photographs in assets/members/ using the filenames already listed in members-data.js.
2. Add the official ESHA Hub logo as assets/esha-hub-logo.png, or change the logo path in both HTML files.
3. Edit verified profile data only in members-data.js.
4. Open executive-members.html first.
